Everything You Need to Manage Rentals
All modules work together in a single coherent workflow — no external apps needed.
🏠

Property Portfolio

Track apartments, villas, offices, shops and warehouses with type, area, bedrooms, floor, furnished status, images and rent amount. Kanban & list views with status badges.

👤

Owner & Renter Profiles

Full profiles for property owners and tenants — phone, email, ID/passport, photo and smart-button counters linking directly to their properties, contracts and payment history.

📄

Rental Contracts

Complete lifecycle: Draft → Active → Expired/Cancelled. On activation, payment schedules are auto-generated based on frequency (Monthly, Quarterly, Bi-Annual, Yearly).

💰

Payment Tracking

Color-coded payments: green (paid), red (late), orange (pending). One-click Mark as Paid, auto-mark overdue via cron, and direct invoice creation linked to Odoo Accounting.

🔧

Maintenance Workflow

Maintenance requests with type (Plumbing, Electrical, HVAC…), priority (Normal / Urgent / Critical), assigned technician, cost tracking and automatic property status sync.

📱

Mobile API & Logs

Generate UUID API keys for mobile app access. Full integration log with endpoint, HTTP method, response code, IP address and duration — ready for Flutter or any mobile client.

📊

Smart Dashboard

Portfolio overview grouped by status and type. Pivot and graph views for performance analysis. Quick filters: Available, Rented, Under Maintenance.

📅

Auto Payment Scheduling

Activating a contract automatically creates all scheduled payment records for the full contract duration, saving hours of manual data entry.

🔔

Chatter & Tracking

Every model has full chatter support — log notes, send messages, schedule activities. Field tracking records who changed what and when on every record.

Screenshots
Properties

Kanban View — Properties by Status

Instant visual overview of your portfolio organised in columns by status. Each card shows property name, type, city and monthly rent.

  • Group by Status, Type, Owner or City
  • Color-coded columns: Available, Rented, Maintenance
  • Switch to List or Pivot view in one click
Contracts

Rental Contract — Full Lifecycle

Each contract links an owner, renter and property. Activating it auto-generates all scheduled payments for the full duration.

  • Status bar: Draft → Active → Expired
  • Auto-generated payments on activation
  • Security deposit tracking
  • Inline payment table with mark-as-paid button
Payments

Rent Payments — Color-Coded Tracking

All payments across all contracts in one place. Rows highlighted green (paid), red (late) and yellow (pending).

  • Paid / Late / Pending / Cancelled statuses
  • One-click Mark as Paid
  • Cron auto-marks overdue as Late
  • Create Odoo invoice directly from payment
Maintenance

Maintenance Requests — Kanban Workflow

Manage repair and service requests from a visual kanban board. Property status updates automatically when work starts and finishes.

  • Types: Plumbing, Electrical, HVAC, Painting…
  • Priority: Normal / Urgent / Critical
  • Estimated vs. actual cost tracking
  • Automatic property status sync
Owners & Renters

Owner & Tenant Profiles

Complete profiles for every owner and tenant with contact details, identity documents and a smart-button counter bar.

  • Phone, email, address and ID/passport number
  • Profile photo support
  • Smart buttons: Properties · Contracts · Payments
  • Full chatter and activity scheduling
Mobile API

API Keys & Integration Logs

Generate secure UUID-based API keys for mobile applications. Every call is logged with endpoint, method, HTTP status and duration.

  • One-click UUID key generation & regeneration
  • Expiry date per key
  • Full call log: method, endpoint, status, duration
  • Enable / disable keys without deletion

🏠

محفظة العقارات

تتبع الشقق والفلل والمكاتب والمحلات والمستودعات مع النوع والمساحة وعدد الغرف والطابق وحالة التأثيث والصور ومبلغ الإيجار. عرض كانبان وقائمة مع شارات الحالة.

👤

ملفات الملاك والمستأجرين

ملفات كاملة للملاك والمستأجرين — الهاتف، البريد الإلكتروني، رقم الهوية، الصورة الشخصية، وأزرار ذكية تربط مباشرة بعقاراتهم وعقودهم وسجل مدفوعاتهم.

📄

عقود الإيجار

دورة حياة كاملة: مسودة ← نشط ← منتهٍ/ملغى. عند التفعيل تُنشأ جداول الدفع تلقائياً حسب التكرار (شهري، ربع سنوي، نصف سنوي، سنوي).

💰

تتبع المدفوعات

مدفوعات ملونة: أخضر (مدفوع)، أحمر (متأخر)، برتقالي (معلق). علّم كمدفوع بنقرة واحدة، وتحديد تلقائي للمتأخرات عبر الجدولة، مع إنشاء فاتورة أودو مباشرةً.

🔧

سير عمل الصيانة

طلبات صيانة مع النوع (سباكة، كهرباء، تكييف…)، الأولوية (عادي / عاجل / حرج)، الفني المسؤول وتتبع التكلفة، مع تحديث تلقائي لحالة العقار.

📱

واجهة برمجية للموبايل

إنشاء مفاتيح API آمنة لتطبيقات الموبايل. سجل متكامل للطلبات يشمل المسار، الطريقة، كود الاستجابة، عنوان IP ومدة التنفيذ — جاهز لتطبيقات Flutter.

📊

لوحة تحكم ذكية

نظرة شاملة على محفظتك مجمّعة حسب الحالة والنوع. عروض محورية وبيانية لتحليل الأداء. فلاتر سريعة: متاح، مؤجر، تحت الصيانة.

📅

جدولة الدفعات التلقائية

عند تفعيل العقد تُنشأ تلقائياً جميع سجلات الدفعات المجدولة لكامل مدة العقد، مما يوفر ساعات من الإدخال اليدوي.

🔔

المحادثات والتتبع

كل نموذج يدعم المحادثة الكاملة — تسجيل ملاحظات، إرسال رسائل، جدولة أنشطة. تتبع الحقول يسجّل من غيّر ماذا ومتى في كل سجل.

لقطات الشاشة
العقارات

عرض كانبان — العقارات حسب الحالة

نظرة بصرية فورية على محفظتك منظمة في أعمدة حسب الحالة. كل بطاقة تعرض اسم العقار، النوع، المدينة وقيمة الإيجار الشهري.

  • تجميع حسب الحالة، النوع، المالك أو المدينة
  • أعمدة ملونة: متاح، مؤجر، تحت الصيانة
  • التبديل إلى عرض القائمة أو المحور بنقرة واحدة
العقود

عقد الإيجار — دورة حياة متكاملة

كل عقد يربط مالكاً ومستأجراً وعقاراً معاً. تفعيل العقد ينشئ تلقائياً جميع دفعات الإيجار لكامل مدة العقد.

  • شريط الحالة: مسودة ← نشط ← منتهٍ
  • إنشاء دفعات تلقائي عند التفعيل
  • تتبع مبلغ التأمين
  • جدول دفعات مدمج مع زر التحديد كمدفوع
المدفوعات

دفعات الإيجار — تتبع ملوّن

جميع المدفوعات من كل العقود في مكان واحد. صفوف مميزة بالأخضر (مدفوع)، الأحمر (متأخر) والأصفر (معلق).

  • حالات: مدفوع / متأخر / معلق / ملغى
  • تحديد كمدفوع بنقرة واحدة
  • جدولة تلقائية لتحديد المتأخرات
  • إنشاء فاتورة أودو مباشرة من الدفعة
الصيانة

طلبات الصيانة — سير عمل كانبان

إدارة طلبات الإصلاح والخدمة من لوحة كانبان بصرية. حالة العقار تتحدث تلقائياً عند بدء العمل وانتهائه.

  • الأنواع: سباكة، كهرباء، تكييف، دهان…
  • الأولوية: عادي / عاجل / حرج
  • تتبع التكلفة التقديرية والفعلية
  • تزامن تلقائي مع حالة العقار
الملاك والمستأجرون

ملفات الملاك والمستأجرين

ملفات كاملة لكل مالك ومستأجر مع بيانات التواصل ووثائق الهوية وشريط أزرار ذكية يعرض الإحصائيات فوراً.

  • الهاتف، البريد، العنوان ورقم الهوية
  • دعم الصورة الشخصية
  • أزرار ذكية: العقارات · العقود · المدفوعات
  • محادثة كاملة وجدولة أنشطة
الواجهة البرمجية

مفاتيح API وسجلات التكامل

أنشئ مفاتيح API آمنة لتطبيقات الموبايل. كل استدعاء يُسجَّل مع المسار والطريقة وكود الاستجابة والمدة.

  • إنشاء وتجديد مفتاح UUID بنقرة واحدة
  • تاريخ انتهاء صلاحية لكل مفتاح
  • سجل كامل: الطريقة، المسار، الحالة، المدة
  • تفعيل وتعطيل المفاتيح دون حذف
